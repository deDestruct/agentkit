# Суть
AI агент доступный по апи имеет вокруг себя лишь минимальные обвзяки харнесса.
Цель дать агенту тулзы для работы с различными форматами входных данных, что бы не забивать контекст написанием в 10-ый раз просмотрщика *.docx
# Упрощенная структура
```
─src/agentkit
    cli.py              # интерфейс командной строки для доступа к инструментам
    └───image           # модуль с инcтрументами для изображений
        annotate.py     # нарисовать на ихображении простой геометрический объект
        cli.py          # регистрация инструментов для изображений
        crop.py         # обрезать изображение
        info.py         # информация об изображении(размер)
        resize.py       # изменить размер изображения с учетом пропорций
        rotate.py       # повернуть изображение
        sheet.py        # объеденить несколько изображений в сетку
    └───pdf             # модуль с инcтрументами для pdf
        info.py         # получить информацию о pdf
```

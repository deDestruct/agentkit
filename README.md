# Суть
AI агент доступный по апи имеет вокруг себя лишь минимальные обвзяки харнесса.
Цель дать агенту тулзы для работы с различными форматами входных данных, что бы не забивать контекст написанием в 10-ый раз просмотрщика *.docx
# Установка
```bash
uv tool install .
agentkit --help
```
Для разработки:
```bash
uv tool install --editable .
```
# Зависимости
- Pillow
- pypdfium2
- python-docx
- lxml

Для рендеринга DOCX на Windows требуется Microsoft Word
# Упрощенная структура
```
─src/agentkit
    cli.py              # интерфейс командной строки для доступа к инструментам
    └───image           # модуль с инcтрументами для изображений
        annotate.py     # нарисовать на ихображении простой геометрический объект
        cli.py          # регистрация инструментов для изображений
        crop.py         # обрезать изображение
        grid.py         # наложить сетку на изображения с отметкой координат
        info.py         # информация об изображении(размер)
        resize.py       # изменить размер изображения с учетом пропорций
        rotate.py       # повернуть изображение
        sample.py       # получить цвета пикселей и статистику цветов области
        sheet.py        # объеденить несколько изображений в сетку
    └───pdf             # модуль с инcтрументами для pdf
        info.py         # получить информацию о pdf
        render.py       # рендерит страницу/страницы с указанным dpi
        text.py         # извлекает доступный текстовый слой
    └── docx/           # модуль для работы с word (render windows only)
        structure.py    # Структура и форматирование
        render.py       # Рендеринг страниц
```
# Политика image-инструментов
- Геометрические преобразования выполняются в пространстве хранимых пикселей.
- EXIF Orientation автоматически не применяется.
- Сохранение метаданных, включая EXIF, ICC и DPI, не гарантируется.
